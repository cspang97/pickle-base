Google Drive 실시간 연동

내 Google Cloud에서 만든 OAuth 클라이언트 ID를 넣으면, 이 브라우저가 내 드라이브의 Pickle_Base 폴더와 Google 문서를 직접 읽어옵니다. 값은 이 브라우저(localStorage)에만 저장되고 어디로도 전송되지 않습니다.

로그인 상태(액세스 토큰)도 이 브라우저에만, 만료 전까지 저장됩니다. 그래서 새로고침하거나 뒤로가기를 눌러도 다시 로그인하지 않습니다. 상단 연결 해제를 누르면 저장된 토큰을 바로 지우고 구글 쪽 토큰도 폐기합니다.

Google Cloud 설정 5단계
  1. Google Cloud Console에서 프로젝트를 만들고 Google Drive API를 사용 설정합니다.
  2. OAuth 동의 화면에서 외부 사용자 유형으로 만들고, 본인 계정을 테스트 사용자로 추가합니다.
  3. 사용자 인증 정보 → OAuth 클라이언트 ID 만들기 → 웹 애플리케이션을 선택합니다.
  4. 승인된 JavaScript 출처에 https://cspang97.github.io 를 추가합니다. (로컬 테스트는 http://localhost:8000)
  5. 발급된 클라이언트 ID를 위 칸에 붙여 넣고 저장한 뒤, 상단의 Google 계정 연결을 누릅니다.

요청 범위는 읽기 전용 drive.readonly 하나입니다. 앱은 드라이브에 쓰지 않습니다.
